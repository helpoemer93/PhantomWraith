========================================================================
                          무기 DPS 정리
========================================================================

각 무기의 Lv0 baseline DPS.
데이터: src/data/Weapons.js
계산 기준: 이론 = 모든 탄 히트, 실전 = 회피/미스 대략 반영
밸런스 기준선: 유도탄 3.0 dps = 1.00x



========================================================================
[기존 무기 5종]
========================================================================


------------------------------------------------------------------------
[1] 직선탄 (basicLinear)
------------------------------------------------------------------------
  발사 간격  : 250ms
  데미지     : 1
  탄속       : 520px/s
  특성       : 관통 없음, 위로만 발사

  DPS:
    이론 최대 (단일 대상, 연속 히트) : 4.00 dps   (1.33x)
    실전 (미스 감안)                 : 2.5~4.0 dps

  참고: 가장 기본적인 지속 화력.


------------------------------------------------------------------------
[2] 관통탄 (piercing)
------------------------------------------------------------------------
  발사 간격  : 400ms
  데미지     : 3
  탄속       : 500px/s
  특성       : 관통, 같은 대상 재히트 쿨 100ms

  DPS:
    단일 대상 (1탄 1히트)     : 7.50 dps   (2.50x)
    단일 대상 (탄 통과 중 2히트) : 15.00 dps  (5.00x, 큰 보스)
    다중 대상 (일렬 정렬)     : 대상 수 x 7.50 dps

  참고: 관통 특성상 잡몹 밀집 상황이나 큰 보스에게 강함.


------------------------------------------------------------------------
[3] 확산탄 (spread)
------------------------------------------------------------------------
  발사 간격  : 550ms  ← 튜닝됨 (600→550)
  데미지     : 1 x 3발 (스프레드 10°)
  탄속       : 480px/s
  특성       : 3발 부채꼴, 관통 없음

  DPS:
    이론 최대 (3발 모두 단일 대상 히트) : 5.45 dps   (1.82x)
    근거리 밀착 (모두 히트)             : 5.45 dps
    중거리 (1발만 히트)                 : 1.82 dps
    다중 대상 (3발 분산 히트)           : 5.45 dps (분산)

  참고: 각도 스프레드 좁아서 근거리 밀착 시 최대 DPS.


------------------------------------------------------------------------
[4] 유도탄 (homing)  [밸런스 기준선]
------------------------------------------------------------------------
  발사 간격  : 333ms
  데미지     : 1
  탄속       : 380px/s (선회속도 180°/s, 가속 100/s²)
  특성       : 유도

  DPS:
    항상 히트 보장 (단일 대상) : 3.00 dps   (1.00x)

  참고: 저점 보장형. 미스가 사실상 없음.


------------------------------------------------------------------------
[5] 궤도탄 (orbit)
------------------------------------------------------------------------
  발사 간격  : 상시 회전 (2π rad/s)
  데미지     : 오브 접촉 1 (500ms 쿨) + 자동 미사일 3 (500ms 간격)
  탄속       : 미사일 380px/s
  특성       : 캐릭터 주변 반경 99 회전, 오브당 자동 미사일 발사

  DPS (오브 1개 기준):
    미사일만 (오브 미접촉)         : 6.00 dps   (2.00x)
    미사일 + 오브 접촉 계속         : 8.00 dps   (2.67x)
    오브만 (접촉 유지, 미사일 X)   : 2.00 dps

  참고: 저점 보장 + 근접 딜.



========================================================================
[신규 무기 4종]
========================================================================


------------------------------------------------------------------------
[6] 부메랑탄 (boomerang)
------------------------------------------------------------------------
  발사 간격  : 500ms  ← 튜닝됨 (550→500)
  데미지     : 갈 때 1 + 올 때 1.5 = 사이클당 2.5
  탄속       : 상승 400px/s → 회귀 600px/s (x1.5)
  특성       : 천장(y=40) 도달 시 회귀, 오너 캐치 시 쿨 -200ms
  판정       : 관통 (재히트 쿨 200ms) → 갈 때·올 때 별개 히트

  DPS:
    갈 때만 히트 (보스 상단)        : 2.00 dps   (0.67x)
    갈 때·올 때 모두 히트 (이상적)  : 5.00 dps   (1.67x)
    갈 때·올 때 히트 + 매번 캐치    : 8.33 dps   (2.78x, 300ms 사이클)

  참고: 캐치 성공 시 유도탄 대비 2.78배까지 뽑음.


------------------------------------------------------------------------
[7] 연쇄번개 (chain)
------------------------------------------------------------------------
  발사 간격  : 975ms  ← 튜닝됨 (780→975, DPS -20% 구구 실측 반영)
  데미지     : 1 (타겟당, 최대 5타겟)
  타겟 선정  : 첫 타겟 = 최근접, 나머지 = 랜덤
  거리 제한  : 없음
  특성       : 즉시 판정, 사슬 라인 220ms fade

  DPS (타겟 수에 따라):
    1 타겟 (보스만)         : 1.03 dps   (0.34x)
    2 타겟                  : 2.05 dps   (0.68x)
    3 타겟                  : 3.08 dps   (1.03x)
    5 타겟 (최대)           : 5.13 dps   (1.71x)

  참고: 잡몹(포탑·자폭드론·라이코) 많은 씬에서 진가.


------------------------------------------------------------------------
[8] 지속광선 (beam)  ← 튜닝됨 (실효 2.73→3.73)
------------------------------------------------------------------------
  발사 간격  : 상시 (프레임 지속)
  데미지     : 틱당 0.7 (틱 주기 100ms)
  판정 폭    : hit 8px + 대상 반경 인식
  오버히트   : 누적 4 데미지 도달 시 0.5초 강제 오프
  특성       : 캐릭터 → 화면 상단 세로 광선, 라인 위 모든 적 다중 히트

  DPS (단일 대상):
    광선 On 상태 순간 DPS       : 7.00 dps   (2.33x)
    오버히트 사이클 실효 DPS    : 3.73 dps   (1.24x)
                                  (571ms on x 7.0) / 1071ms cycle
    광선이 대상 벗어남          : 0 dps

  DPS (다중 대상):
    라인 위 N개 대상            : 실효 DPS x N (전부 동시 히트)
    but 오버히트도 N배로 빨리 도달 → 온 시간 짧아짐

  참고: 캐릭터 X 정렬 필수 (대상 반경 인식 후 hitWidth 8 + 반경).
        직선탄(4.00) 대비 실효 93%.


------------------------------------------------------------------------
[9] 시한지뢰 (mine)
------------------------------------------------------------------------
  발사 간격  : 1200ms
  데미지     : 폭발 미사일 8발 x 1 = 총 8 (풀히트 시)
  탄속       : 지뢰 480→60px/s 감속, 폭발탄 300px/s
  특성       : 지뢰 자체 판정 있음(데미지 0), 적 접촉 or y≤140 시 폭발
               폭발 시 사방 8발 균등

  DPS:
    풀히트 (8발 모두 명중, 이상적)   : 6.67 dps   (2.22x)
    실전 (근접 폭발, 3~4발 히트)     : 2.5~3.3 dps
    실전 (원거리 자동 폭발, 1~2발)   : 0.83~1.67 dps

  참고: 8발이 사방으로 나가므로 대상이 폭발 지점 근처여야 여러 발 히트.

튜닝 참고
========================================================================

  · 밸런스 기준: 유도탄 1.00x (실전 = 이론, 변수 0)

  · 단일 보스 DPS 순위 (조건 만족 시):
    궤도탄 > 관통탄 > 시한지뢰 > 확산탄 > 부메랑 > 직선탄 > 광선 > 유도탄

  · 다중 대상 (5마리 밀집):
    연쇄번개(5.13) > 관통탄(35+, 일렬) > 지속광선(x5, 정렬)
    > 시한지뢰(폭발 반경)

  · 잡몹 밀집 페이즈 (메타그로스 페1/3, 두파팡 페2 스파이럴):
    연쇄번개·관통탄 강점 페이즈

  · 단일 보스 페이즈 (구구·프리져 대부분):
    관통탄·궤도탄이 안정적. 유도탄으로 저점 보장.

  · 신규 4종은 아직 Lv 스케일 미정. 대응 보스 만들어지면서 튜닝 예정.
