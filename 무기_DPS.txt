========================================================================
                          무기 DPS 정리
========================================================================

각 무기의 Lv0 baseline DPS + Lv10 최대 성장.
데이터: src/data/Weapons.js  (MAX_WEAPON_LEVEL = 10)
계산 기준: 이론 = 모든 탄 히트, 실전 = 회피/미스 대략 반영
밸런스 기준선: 유도탄 Lv0 3.0 dps = 1.00x

[기존 무기 5종]
========================================================================


------------------------------------------------------------------------
[1] 직선탄 (basicLinear)
------------------------------------------------------------------------
  발사 간격  : 250ms
  데미지     : 1
  탄속       : 520px/s
  특성       : 관통 없음, 위로만 발사

  DPS:
    이론 최대 (단일 대상, 연속 히트) : 4.00 dps   (1.33x)
    실전 (미스 감안)                 : 2.5~4.0 dps

  레벨 성장 (Lv당 rate +15%):
    · intervalMs = 250 / 1.15^lv
    · Lv5:  interval 124ms, 이론  8.05 dps  (2.68x)
    · Lv10: interval  62ms, 이론 16.13 dps  (5.38x)

  참고: 가장 기본적인 지속 화력.


------------------------------------------------------------------------
[2] 관통탄 (piercing)
------------------------------------------------------------------------
  발사 간격  : 400ms
  데미지     : 3
  탄속       : 500px/s
  특성       : 관통, 같은 대상 재히트 쿨 100ms

  DPS:
    단일 대상 (1탄 1히트)     : 7.50 dps   (2.50x)
    단일 대상 (탄 통과 중 2히트) : 15.00 dps  (5.00x, 큰 보스)
    다중 대상 (일렬 정렬)     : 대상 수 x 7.50 dps

  레벨 성장 (Lv당 rate +10%, 크기 +5%):
    · intervalMs = 400 / 1.10^lv,  width/height x 1.05^lv
    · Lv5:  interval 248ms, 이론 12.10 dps 1히트 / 24.19 dps 2히트, 크기 1.28x
    · Lv10: interval 154ms, 이론 19.42 dps 1히트 / 38.85 dps 2히트, 크기 1.63x

  참고: 관통 특성상 잡몹 밀집 상황이나 큰 보스에게 강함.
        크기 성장으로 큰 보스에서 2히트 확률 상승.


------------------------------------------------------------------------
[3] 확산탄 (spread)
------------------------------------------------------------------------
  발사 간격  : 550ms  ← 튜닝됨 (600→550)
  데미지     : 1 x 3발 (스프레드 10°)
  탄속       : 480px/s
  특성       : 3발 부채꼴, 관통 없음

  DPS:
    이론 최대 (3발 모두 단일 대상 히트) : 5.45 dps   (1.82x)
    근거리 밀착 (모두 히트)             : 5.45 dps
    중거리 (1발만 히트)                 : 1.82 dps
    다중 대상 (3발 분산 히트)           : 5.45 dps (분산)

  레벨 성장 (2Lv마다 탄수 +1, Lv당 rate +4%):
    · pellets = 3 + floor(lv/2),  intervalMs = 550 / 1.04^lv
    · Lv5:  5발, interval 452ms → 근접 밀착 11.06 dps (2.03x)
    · Lv10: 8발, interval 371ms → 근접 밀착 21.56 dps (3.96x)

  참고: 각도 스프레드 좁아서 근거리 밀착 시 최대 DPS.


------------------------------------------------------------------------
[4] 유도탄 (homing)  [밸런스 기준선]
------------------------------------------------------------------------
  발사 간격  : 333ms
  데미지     : 1
  탄속       : 380px/s (선회속도 180°/s, 가속 100/s²)
  특성       : 유도

  DPS:
    항상 히트 보장 (단일 대상) : 3.00 dps   (1.00x)

  레벨 성장 (Lv당 rate +15%):
    · intervalMs = 333 / 1.15^lv
    · Lv5:  interval 166ms, 이론  6.03 dps  (2.01x)
    · Lv10: interval  82ms, 이론 12.15 dps  (4.05x)

  참고: 저점 보장형. 미스가 사실상 없음.


------------------------------------------------------------------------
[5] 궤도탄 (orbit)
------------------------------------------------------------------------
  발사 간격  : 상시 회전 (2π rad/s)
  데미지     : 오브 접촉 1 (500ms 쿨) + 자동 미사일 3 (500ms 간격)
  탄속       : 미사일 380px/s
  특성       : 캐릭터 주변 반경 99 회전, 오브당 자동 미사일 발사

  DPS (오브 1개 기준):
    미사일만 (오브 미접촉)         : 6.00 dps   (2.00x)
    미사일 + 오브 접촉 계속         : 8.00 dps   (2.67x)
    오브만 (접촉 유지, 미사일 X)   : 2.00 dps

  레벨 성장 (2Lv마다 궤도 +1, 데미지는 그대로):
    · orbCount = 1 + floor(lv/2)
    · Lv5:  3궤도 → 미사일+오브 접촉 24.00 dps  (3.00x)
    · Lv10: 6궤도 → 미사일+오브 접촉 48.00 dps  (6.00x)

  참고: 저점 보장 + 근접 딜.
        궤도수 성장만으로 곱셈 스케일이라 데미지 성장 없이도 충분.

[6] 부메랑탄 (boomerang)
------------------------------------------------------------------------
  발사 간격  : 500ms  ← 튜닝됨 (550→500)
  데미지     : 갈 때 1 + 올 때 1.5 = 사이클당 2.5
  탄속       : 상승 400px/s → 회귀 600px/s (x1.5)
  특성       : 천장(y=40) 도달 시 회귀, 오너 캐치 시 쿨 -200ms
  판정       : 관통 (재히트 쿨 200ms) → 갈 때·올 때 별개 히트

  DPS:
    갈 때만 히트 (보스 상단)        : 2.00 dps   (0.67x)
    갈 때·올 때 모두 히트 (이상적)  : 5.00 dps   (1.67x)
    갈 때·올 때 히트 + 매번 캐치    : 8.33 dps   (2.78x, 300ms 사이클)

  레벨 성장 (Lv당 rate +7.5%, 크기 +7.5%):
    · intervalMs = 500 / 1.075^lv,  width/height x 1.075^lv
    · Lv5:  interval 348ms, 이상 7.19 dps  (1.44x), 크기 1.44x
    · Lv10: interval 243ms, 이상 10.29 dps (2.06x), 크기 2.06x
    · 캐치 시 사이클 = interval - 200ms → Lv10 43ms 사이클 (화면 부메랑 다수)

  참고: 캐치 성공 시 유도탄 대비 2.78배까지 뽑음.

[7] 연쇄번개 (chain)
------------------------------------------------------------------------
  발사 간격  : 975ms  ← 튜닝됨 (780→975, DPS -20% 구구 실측 반영)
  데미지     : 1 (타겟당, 최대 3타겟) ← 5→3 (메타그로스 압도적 퍼포먼스 조정)
  타겟 선정  : 첫 타겟 = 최근접, 나머지 = 랜덤
  거리 제한  : 없음
  특성       : 즉시 판정, 사슬 라인 220ms fade, 튕길수록 -10%

  DPS (타겟 수에 따라, falloff 0.10 반영):
    1 타겟 (보스만)         : 1.03 dps   (0.34x)
    2 타겟 (1.0 + 0.9)      : 1.95 dps   (0.65x)
    3 타겟 (최대, +0.81)    : 2.78 dps   (0.93x)

  레벨 성장 (Lv당 rate +15%):
    · intervalMs = 975 / 1.15^lv
    · Lv5:  interval 485ms → 3타겟  5.60 dps (1.87x)
    · Lv10: interval 241ms → 3타겟 11.24 dps (3.75x)
    · 1타겟 저점도 자연 성장: Lv10 4.15 dps (Lv0 1.03의 4.05x)

  참고: 잡몹(포탑·자폭드론·라이코) 많은 씬에서 진가.

[8] 지속광선 (beam)  ← 튜닝됨 (실효 2.73→3.73)
------------------------------------------------------------------------
  발사 간격  : 상시 (프레임 지속)
  데미지     : 틱당 0.7 (틱 주기 100ms)
  판정 폭    : hit 8px + 대상 반경 인식
  오버히트   : 누적 4 데미지 도달 시 0.5초 강제 오프
  특성       : 캐릭터 → 화면 상단 세로 광선, 라인 위 모든 적 다중 히트

  DPS (단일 대상):
    광선 On 상태 순간 DPS       : 7.00 dps   (2.33x)
    오버히트 사이클 실효 DPS    : 3.73 dps   (1.24x)
                                  (571ms on x 7.0) / 1071ms cycle
    광선이 대상 벗어남          : 0 dps

  DPS (다중 대상):
    라인 위 N개 대상            : 실효 DPS x N (전부 동시 히트)
    but 오버히트도 N배로 빨리 도달 → 온 시간 짧아짐

  레벨 성장 (Lv당 dmg +7.5%, threshold +7.5%, 폭 선형):
    · damage x 1.075^lv,  overheatThreshold x 1.075^lv
    · visualWidth = 14 + 1.5*lv,  hitWidth = 8 + 1.0*lv
    · Lv5:  dmg 1.005/tick, threshold 5.74, 실효 5.28 dps (1.42x), 시각 21.5px
    · Lv10: dmg 1.442/tick, threshold 8.24, 실효 7.57 dps (2.03x), 시각 29px
    · 다중 대상은 hitWidth 성장(2.25x)으로 실전 확률·범위 크게↑

  참고: 캐릭터 X 정렬 필수 (대상 반경 인식 후 hitWidth 8 + 반경).
        직선탄(4.00) 대비 실효 93%.

[9] 시한지뢰 (mine)
------------------------------------------------------------------------
  발사 간격  : 1200ms
  데미지     : 폭발 미사일 8발 x 1 = 총 8 (풀히트 시)
  탄속       : 지뢰 480→60px/s 감속, 폭발탄 300px/s
  특성       : 지뢰 자체 판정 있음(데미지 0), 적 접촉 or y≤140 시 폭발
               폭발 시 사방 8발 균등

  DPS:
    풀히트 (8발 모두 명중, 이상적)   : 6.67 dps   (2.22x)
    실전 (근접 폭발, 3~4발 히트)     : 2.5~3.3 dps
    실전 (원거리 자동 폭발, 1~2발)   : 0.83~1.67 dps

  레벨 성장 (Lv당 rate +7.5%, 크기 선형):
    · intervalMs = 1200 / 1.075^lv
    · mineRadius = 8 + 0.85*lv,  explosionBulletRadius = 3 + 0.32*lv
    · explosionBulletHitRadius = 18 + 1.9*lv
    · Lv5:  interval 836ms, 지뢰 12.3, 파편 4.6/27.5,  이상 9.57 dps (1.44x)
    · Lv10: interval 583ms, 지뢰 16.5, 파편 6.2/37.1,  이상 13.72 dps (2.06x)
    · hitRadius 성장으로 실전 히트율 크게↑ (실전 배율은 이론보다 더 큼)

  참고: 8발이 사방으로 나가므로 대상이 폭발 지점 근처여야 여러 발 히트.

튜닝 참고
========================================================================

  · 밸런스 기준: 유도탄 1.00x (실전 = 이론, 변수 0)

  · 단일 보스 DPS 순위 (조건 만족 시):
    궤도탄 > 관통탄 > 시한지뢰 > 확산탄 > 부메랑 > 직선탄 > 광선 > 유도탄

  · 다중 대상 (3마리 이상 밀집):
    관통탄(35+, 일렬) > 지속광선(x5, 정렬) > 연쇄번개(2.78, 3타겟 상한)
    > 시한지뢰(폭발 반경)

  · 잡몹 밀집 페이즈 (메타그로스 페1/3, 두파팡 페2 스파이럴):
    연쇄번개·관통탄 강점 페이즈

  · 단일 보스 페이즈 (구구·프리져 대부분):
    관통탄·궤도탄이 안정적. 유도탄으로 저점 보장.

  · 성장 방향 설계 원칙 (2026-08-12 개편):
    - 단일 스탯 성장: rate +15%/Lv (basicLinear, homing, chain)
    - 복합 성장 (수량+): pellets/orbCount 등 +1/2Lv + 낮은 rate 성장
    - damage 직접 성장은 최소화 (piercing·spread·homing·orbit 전부 rate/수량으로 전환)
    - 신규 4종은 눈에 띄는 성장 요소 우선 (크기·굵기·개수)

  · Lv10 배율 범위: 2.03x (beam) ~ 6.00x (orbit)
    - orbit이 궤도수 곱셈으로 여전히 최고. 근접 유지 조건 감안 정당.
    - beam 저성장은 damage/threshold 곱셈이라 실효 DPS가 damage 배율만큼만 상승.
    - 부메랑·지뢰(2.06x) 저성장은 눈에 띄는 크기/공속 성장으로 체감 보완.
